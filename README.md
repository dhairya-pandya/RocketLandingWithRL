# RocketLandingWithRL

A 2D rocket learns to land on a moving, rocking drone ship in gusty wind. The physics, the
environment and every reinforcement learning algorithm (PPO, SAC, TD3, GRPO, REINFORCE, CEM/ES)
are written from scratch in Python and PyTorch, trained on a laptop CPU, and compared against a
hand-written PID controller.

Work in progress.
